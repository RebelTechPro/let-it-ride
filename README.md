# Let It Ride

Let It Ride poker as an installable web app that works offline. It includes a basic-strategy coach, a 3-card bonus bet, and full hand, session and decision tracking stored in the browser.

**Play:** https://rebeltechpro.github.io/let-it-ride/

On Android, open the link in Chrome and choose **⋮ → Install app**. After one visit it runs with no internet.

When you change a file, bump `VERSION` in `sw.js` so installed copies pick up the update.
